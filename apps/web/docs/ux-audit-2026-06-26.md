# UX Heuristic Audit — BBPC Main Page

**Date:** 2026-06-26
**Auditor:** Automated heuristic evaluation (Nielsen 10 + Krug laws)
**Scope:** Homepage (`/`) — layout, navigation, LatestEpisode, NextEpisode, footer

---

## Score: **6 / 10** (before fixes)

The core content presentation (episode cards, movie posters, audio player) is functional. However, the page had several structural issues — hidden navigation, ambiguous date formats, gratuitous animation, inconsistent footer, and visual clutter — that create unnecessary cognitive load and fail the "Trunk Test."

---

## Fixes Applied (After)

### 1. Navigation — Desktop Horizontal Bar
**File:** `src/components/NavMenu.tsx`
- Added a horizontal nav bar visible on `md:` breakpoint and above
- Each item shows icon + text label ("Home", "History", "Game", "Tags", "Year", "Merch", "About")
- Mobile dropdown preserved for small screens
- Auth-aware items (Syllabus, Profile, Logout) appear only when logged in

### 2. Page Orientation — H1 + Readable Tagline
**File:** `src/app/layout.tsx`
- Added visible `<h1>Bad Boys Podcast</h1>` as page heading
- Changed tagline from invisible `text-red-900` to readable `text-gray-400`
- Added proper spacing between heading and tagline

### 3. PredictionGame Removed from Homepage
**File:** `src/components/NextEpisode.tsx`
- Removed `allowGuesses={true}` prop from NextEpisode on homepage
- Homepage now shows only episode content — no game clutter
- PredictionGame still available on `/game` page

### 4. Date Format — Unambiguous "Jun 26, 2026"
**Files:** `src/components/LatestEpisode.tsx`, `src/components/Episode.tsx`
- Removed `{ month: "2-digit", day: "2-digit", year: "2-digit" }` override
- Now uses `formatPlainDate()` default: `"short"` month + `"numeric"` day + `"numeric"` year
- Produces: "Jun 26, 2026" — unambiguous across all locales

### 5. Footer — Unified Platform Badges
**File:** `src/components/ListenHere.tsx`
- All platform links now rendered at consistent height (~40px visual)
- Added "Listen on" label for orientation
- Used uniform `opacity-70 → hover:opacity-100` transition
- Replaced oversized/mismatched badges with standardized sizes

### 6. NextEpisode — Compact "Coming Soon" Card
**Files:** `src/components/NextEpisode.tsx`, `src/app/page.tsx`
- Added `compact` prop to NextEpisode component
- Compact mode: slim card with "Coming Soon" label, episode number, title, and small thumbnails
- Homepage uses compact mode; other pages retain full mode
- Reduces vertical space from ~400px to ~120px

### 7. Trophy Animation Removed
**File:** `src/components/LatestEpisode.tsx`
- Removed `animate-bounce` class from both Trophy icons
- Retained `group-hover:scale-110` for subtle interactive feedback on hover

### 8. Episode Section Background
**Files:** `src/components/LatestEpisode.tsx`, `src/components/Episode.tsx`, `src/components/NextEpisode.tsx`
- Changed section backgrounds from `bg-transparent` to `bg-gray-900/30`
- Gives cards visual substance against the gradient background
